# Google Calendar Multi-Day Grid Viewer

This userscript changes how multi-day events are displayed in Google Calendar. Instead of stacking multi-day events in the "all-day" section at the top of the calendar, it visually places them inside the hourly grid, spanning across the appropriate days and times.

## Features

- **Grid Placement**: Multi-day events are rendered within the actual time grid, matching their start and end hours.
- **Accurate Time Mapping**: Events correctly span their exact duration across multiple days.

## Installation

1. Install a userscript manager like [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Click the link below to install the script:
