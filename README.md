## Google Forms

[Google Forms Auto Fill](https://raw.githubusercontent.com/nihaltp/uscripts/main/google_forms/dist/google-forms-saver.user.js) - A script to automatically fill Google Forms with saved data, making it easier to complete forms quickly.

<details>
<summary>Features</summary>

- Save multiple form responses per form for quick reuse.
- Manage saves directly from a floating action button on any Google Form.
- Conflict resolution interface when merging saved values with current form data.
- Auto-loads automatically if there is only a single save for a given form.
- Edit, rename, and delete saved form responses directly within the modal.
- Support for various form field types (text, linear scales, dates, dropdowns, radios, and checkboxes).

</details>
